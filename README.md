# Trainee Hub

ระบบบริหารจัดการเทรนนี่ พี่เลี้ยง และโปรเจ็ค (Trainee Management System)

หน้าเว็บไซต์ (Page) ทั้งหมดของระบบ โดยยังไม่ได้จำกัดสิทธิ์การเข้าถึงตามบทบาท (Role-based Access) เพื่อให้เห็นภาพรวมฟังก์ชันทั้งหมดของระบบก่อน แต่ละหน้าจะระบุผู้ใช้งานที่เกี่ยวข้องหลัก (เทรนนี่ / พี่เลี้ยง / แอดมิน) ไว้เป็นข้อมูลอ้างอิงเท่านั้น รวมทั้งสิ้น 15 หมวดหมู่ 40 หน้า

สารบัญหน้าเว็บไซต์ (Page Index)

หมวดหมู่หน้า1. บัญชีผู้ใช้งานเข้าสู่ระบบ, สมัครสมาชิก, ลืม/รีเซ็ตรหัสผ่าน2. หน้าหลักภาพรวมของฉัน (Home), Dashboard ภาพรวมระบบ3. โปรไฟล์โปรไฟล์ของฉัน, รายชื่อ/รายละเอียดเทรนนี่, รายชื่อ/รายละเอียดพี่เลี้ยง4. การจัดการงานKanban งานของฉัน, รายละเอียดงาน, สร้าง/มอบหมายงาน, Kanban ทีม, คิว Review งาน5. นัดหมายปฏิทิน/ตารางนัดหมาย, สร้างนัดหมาย, รายละเอียดนัดหมาย6. เอกสารรายการเอกสาร, อัปโหลดเอกสาร, ดูรายละเอียดเอกสาร7. โปรเจ็ครายการโปรเจ็ค, รายละเอียดโปรเจ็ค, แก้ไข Diagram ขั้นตอน, สร้างโปรเจ็คใหม่8. บทความ/ความรู้รายการบทความ, รายละเอียดบทความ, สร้าง/แก้ไขบทความ, คิวอนุมัติบทความ9. ขยายเวลาฝึกงานยื่นคำขอขยายเวลา, รายการคำขอขยายเวลา10. คำขอกำลังคนยื่นคำขอกำลังคน, รายการคำขอกำลังคน11. ปัญหาและ Feedbackแจ้งปัญหา, รายการปัญหา, Feedback12. Standup และการลาเช็คอิน Standup, ยื่นคำขอลา, รายการการลา13. การแจ้งเตือนศูนย์การแจ้งเตือน, ตั้งค่าการแจ้งเตือน14. ค้นหาและรายงานผลการค้นหา/กรองข้อมูล, Export รายงาน15. จัดการระบบ (Admin)จัดการผู้ใช้งานและสิทธิ์, จัดการข้อมูลอ้างอิง (Master Data)

1. บัญชีผู้ใช้งาน (Authentication)

1.1 หน้าเข้าสู่ระบบ (Login)

ผู้ใช้งานที่เกี่ยวข้อง: เทรนนี่ / พี่เลี้ยง / แอดมิน

ช่องกรอกอีเมล/Username และรหัสผ่าน

ปุ่มเข้าสู่ระบบ

ลิงก์ไปหน้าสมัครสมาชิก

ลิงก์ไปหน้าลืมรหัสผ่าน

1.2 หน้าสมัครสมาชิก (Register)

ผู้ใช้งานที่เกี่ยวข้อง: เทรนนี่

ฟอร์มกรอกข้อมูลเบื้องต้น: ชื่อเล่น, อีเมล, รหัสผ่าน, ทีมเทรนนี่, บ้าน

ปุ่มยืนยันการสมัคร

ข้อความแจ้งเตือนกรณีติดขัดให้ติดต่อแอดมินเพื่อสร้างบัญชีให้

1.3 หน้าลืมรหัสผ่าน / รีเซ็ตรหัสผ่าน (Forgot / Reset Password)

ผู้ใช้งานที่เกี่ยวข้อง: เทรนนี่ / พี่เลี้ยง / แอดมิน

ช่องกรอกอีเมลเพื่อขอลิงก์รีเซ็ต

ฟอร์มตั้งรหัสผ่านใหม่ (เมื่อกดลิงก์จากอีเมล)

2. หน้าหลัก (Home & Dashboard)

2.1 หน้าภาพรวมของฉัน (My Home)

ผู้ใช้งานที่เกี่ยวข้อง: เทรนนี่ / พี่เลี้ยง

สรุปงานที่ต้องทำวันนี้ / ที่ยังไม่เสร็จ

นัดหมายที่ใกล้ถึง

การแจ้งเตือนล่าสุด

ทางลัดไปยังฟีเจอร์หลัก (มอบหมายงาน, อัปโหลดเอกสาร, ดูบทความ)

2.2 หน้า Dashboard ภาพรวมระบบ (System Dashboard)

ผู้ใช้งานที่เกี่ยวข้อง: แอดมิน

ระยะเวลาการฝึกงานของเทรนนี่: วันที่เริ่ม/จบ/จำนวนวันรวม

จำนวนเทรนนี่เข้าใหม่ในแต่ละรอบ และที่กำลังจะฝึกจบ

สัดส่วนเทรนนี่ที่มีงาน/ว่างงาน

จำนวนเทรนนี่ต่อโปรเจ็ค

สถิติ Standup / ลาป่วย / ลากิจ

การคาดการณ์จำนวนเทรนนี่ในอนาคต (ช่วงพีค)

ตาราง Demand/Supply กำลังคนต่อโปรเจ็ค/ทีม/บ้าน

ปุ่ม Export Dashboard เป็น PDF/Excel

ตัวกรอง: ทีม, บ้าน, โปรเจ็ค, สถานะมีงาน/ว่างงาน

ช่องค้นหาชื่อเทรนนี่

3.3 หน้ารายละเอียดเทรนนี่ (Trainee Detail)

ผู้ใช้งานที่เกี่ยวข้อง: พี่เลี้ยง / แอดมิน

สถานะปัจจุบัน (มีงาน/ว่างงาน)

พี่เลี้ยงที่ดูแล

เอกสารที่เทรนนี่ส่งมา

3.4 หน้ารายชื่อพี่เลี้ยง (Mentor Directory)

ผู้ใช้งานที่เกี่ยวข้อง: แอดมิน / เทรนนี่

ตารางรายชื่อพี่เลี้ยงทั้งหมด

ตัวกรอง: ทีมพี่เลี้ยง, โปรเจ็ค

3.5 หน้ารายละเอียดพี่เลี้ยง (Mentor Detail)

ผู้ใช้งานที่เกี่ยวข้อง: แอดมิน / เทรนนี่

ข้อมูลโปรไฟล์พี่เลี้ยง

รายชื่อเทรนนี่ที่ดูแล

โปรเจ็คที่รับผิดชอบ

4.1 หน้า Kanban งานของฉัน (My Task Board)

4.3 หน้าสร้าง/มอบหมายงาน (Create Task)

ผู้ใช้งานที่เกี่ยวข้อง: พี่เลี้ยง

เลือกรูปแบบมอบหมาย: มอบหมายทีเดียวหลายคน หรือมอบหมายทีละคน

เลือกเทรนนี่ผู้รับมอบหมาย

ช่องแนบเอกสารประกอบ

4.4 หน้า Kanban ติดตามทีม (Team Task Board)

ผู้ใช้งานที่เกี่ยวข้อง: พี่เลี้ยง

ตัวกรองตามโปรเจ็ค/เทรนนี่/สถานะ

4.5 หน้าคิว Review งาน (Task Review Queue)
